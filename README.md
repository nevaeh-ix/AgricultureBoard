# AgricultureBoard 🌱

A planting planner that combines live weather, crop presets, and estimated planting and harvest dates.

**Tech:** JavaScript, HTML/CSS, Open-Meteo API, localStorage

**Features:** Location search, 12 crop presets (including corn, tomatoes, and potatoes), planting recommendations, and editable saved garden plans.

## Run locally

```bash
python -m http.server 8000
```

Open http://localhost:8000. No API key required.

Planting dates are estimates, not guarantees. Saved crops stay in your browser. Weather: [Open-Meteo](https://open-meteo.com/). Planting reference: [NC State Extension](https://content.ces.ncsu.edu/central-north-carolina-planting-calendar-for-annual-vegetables-fruits-and-herbs).
